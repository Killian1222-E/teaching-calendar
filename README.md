# 課程行事曆

給樂高教育 / Minecraft 教育版老師用的排課工具。電腦和手機同一份資料，
說一句話就能排課，不用碰 Google 日曆。

---

## 先看這裡：上傳 GitHub 時的重點

解壓縮後你會看到一個資料夾，裡面**第一層**就有 `package.json`、`src`、
`android`、`.github` 這些東西 —— **這一層就是專案根目錄**。

上傳 GitHub 時，`package.json` 必須出現在 repository 的**第一頁**。
如果點進 repository 後看到的是「再一層資料夾」，那就是包錯了，
自動建置會失敗（找不到 package.json）。

另外 `.github` 這個資料夾**一定要一起上傳**，自動建 APK 和網頁全靠它。
它是以點開頭的隱藏資料夾：

- **Windows**：檔案總管 →「檢視」→ 勾選「隱藏的項目」
- **macOS**：Finder 按 `Cmd + Shift + .` 顯示隱藏檔案

用網頁拖拉上傳容易漏掉隱藏資料夾，**建議用 GitHub Desktop**
（把整個資料夾拖進去 → Publish repository），它不會漏。

## 三十秒上手

1. **電腦**：打開網址 → 網址列右邊的「安裝」圖示 → 變成獨立視窗的 App
2. **手機**：打開同一個網址 → 選單「加到主畫面」→ 桌面出現圖示
3. **AI 助理**分頁輸入一句話，例如：

```
8/25 1300-1430 三民分校 Minecraft 學生組B、不是代課，上次Minecraft 狗狗圍欄
```

助理會拆成日期、時間、地點、課程、班級、代課與上次進度，
確認後按「加入行事曆」就完成了。

## 它會做什麼

### 一句話排課

助理看得懂的寫法（不需要固定格式）：

| 你說 | 它排出來 |
| --- | --- |
| `8/25 1300-1430 三民分校 Minecraft 學生組B` | 單堂課 |
| `明天下午2點到3點半 樂高 代課` | 明天的代課 |
| `9月每週一 1400-1530 三民分校 樂高 學生組B` | 整個九月的週一課程 |
| `每週二、四 1600-1730 學生組A 連續3週` | 六堂課 |
| `9/20 0900-1600 中鋼大活動 80人` | 一場 80 人的大活動 |
| `9/8 三民分校 代課 6個學生` | 代課，人數 6 |
| `9/7 停課` | 把那天的課標記停課 |
| `9/7 的課改到 9/14` | 改期 |
| `學生組B上次上到哪` | 直接回答，不會亂排課 |

**別人傳來的代課邀請可以整段複製貼上**，一天好幾節、跨好幾天都認得：

```
品品老師以下時間是可以請您幫忙代課嗎?

9/5(六):
第一班0830-1000
第二班1030-1200
第三班1400-1530

9/8(二)18:30-20:00
9/9(三)19:00-20:30

都在三民上課
```

會展開成一筆一筆的課程，而且：

- 日期標題底下的每個時段都掛到那一天
- 開頭的「幫忙代課」讓全部自動標成代課
- 最後那句「都在三民」套用到全部（簡稱也認得，會對到「三民分校」）
- 「第一班」「第二班」是**節次**不是班級，會存成備註，不會亂建班級
- 代課不會被固定課表硬塞你自己的學生組

日期支援 `8/25`、`8月25日`、`九月十五日`、`明天`、`下週三`、`9/1到9/30`。
時間支援 `1300-1430`、`13:00~14:30`、`下午1點到2點半`、`1400 90分鐘`。

### 記住你的固定課表

第一次排「星期一 14:00–15:30 學生組B」時，助理會問要不要記起來。
記起來之後，你只要說 `9/1 一樣的課`，班級、地點、課程就自動帶入，
畫面上會標示「固定課表推斷」讓你確認。你另外講的內容永遠優先。

### 上次上到哪

填了「這堂課上的內容」之後，下一堂同班級的課就會自己顯示「上次上到 ⋯」。

同一個班級每週課程不一樣也沒問題（這週 Minecraft、下週 Scratch）：

- **同一門課的進度**單獨追蹤，不會被別門課蓋掉
- 另外顯示**上一次見面**做了什麼
- 沒講這次要上哪一門時，助理會提醒你指定，不會照上週亂猜

### 班級、代課、大活動

三種情況分開處理：

- **常態班級** — 學生名單存在班級底下，人數自動帶到每一堂課
- **代課** — 帶的不是自己的學生，名字直接記在那堂課上，不會污染班級名單；
  也可以只填人數
- **大活動** — 像去中鋼那種 80 人的場子。不綁班級，填活動名稱和人數就好，
  系統會標示小場 / 中場 / 大場

月曆格子上直接顯示班級名稱（顏色是課程），點日期下方的「名單快捷」
或課程卡片上的人數徽章，馬上看到這一班有誰。

### 時間撞在一起會提醒

同一天有兩堂課時段重疊時（常見於還在跟人喬時間），**月曆上那天的日期會變紅字**
右上角還有一個紅點。點下去，日期下面會出現一條紅色提示，列出是哪幾個時段撞到。

它只是提醒，不會擋你。喬定了再去改時間或刪掉其中一堂就好。

### 手機上的操作

- 月曆固定七欄，週六不會被切掉
- 最上面的年份月份、月曆／清單切換、星期列**捲動時會釘在上面**
- AI 助理的輸入列**永遠在最下面**，鍵盤跳出來也不會被蓋住

### 其他

- 出席可以逐一點名（到 / 遲 / 缺）
- 淺色 / 深色 / 跟隨系統，右上角一鍵切換
- 完全離線可用，沒網路照樣排課，連上線自動同步
- 備份匯出成 JSON

## 兩台裝置同步

資料存在**你自己的 Supabase 專案**，不經過任何第三方。免費方案完全夠用。

1. 到 [supabase.com](https://supabase.com) 註冊，建一個新專案
2. 左邊選單 **SQL Editor** → 貼上本專案的 `supabase/schema.sql` 整份 → Run
3. 左邊選單 **Project Settings → API**，複製兩樣東西：
   - Project URL
   - `anon` `public` key
4. App 裡「設定 → 雲端同步」貼上這兩個，按「儲存連線資訊」
5. 用 Email + 密碼**註冊**一組帳號（這是你自己的，只有你看得到）
6. 手機用**同一組帳號登入**，按「從雲端重新下載」

之後兩邊都會自動同步（回到前景時、每兩分鐘一次、手動按也可以）。
衝突處理是「後改的贏」，刪除也會同步。

> `schema.sql` 可以重複執行，之後版本更新有新欄位時再貼一次就好。

## AI 備援（選用，不設定也能用）

內建的中文解析器離線就能處理絕大多數句子，不花錢。
只有它看不懂時才會問 AI。

「設定 → AI 備援」選 Claude 或 OpenAI，貼上自己的 API key。
key 只存在那台裝置，不會同步上雲端。

## 手機 App（APK）

### 方法一：加到主畫面（最快，不用 APK）

手機瀏覽器開網址 → 選單 →「加到主畫面 / 安裝應用程式」。
會有自己的圖示、全螢幕、離線可用，跟一般 App 幾乎一樣。

### 方法二：真的 APK（GitHub 免費幫你編）

1. 把整包程式上傳到 GitHub（新建一個 repository，可以設 Private）
2. 進 **Actions** 分頁 → 左邊「**建立簽名金鑰**」→ Run workflow
   → 輸入別名和密碼 → 跑完下載 Artifacts 裡的資料夾，
   照裡面 `README.txt` 設好三個 secrets（這步只要做一次）
3. **Actions** → 「**建置 Android APK**」→ Run workflow
4. 跑完後在頁面最下面 **Artifacts → apk** 下載，傳到手機安裝
   （第一次安裝要允許「安裝未知來源的應用程式」）

沒設定金鑰也能直接跑第 3 步，會產生測試版 APK，一樣可以裝，
只是之後更新要先解除安裝。

### 方法三：自己在電腦上編

需要 Android Studio。

```bash
npm install
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
# APK 在 android/app/build/outputs/apk/debug/
```

## 電腦版

網頁版在 Chrome / Edge 直接「安裝」就是獨立視窗的桌面 App，
有自己的圖示，離線可用。

要放在自己電腦上跑：

```bash
npm install
npm run build
npm run preview      # 打開 http://localhost:4173
```

或把 `dist/` 資料夾丟到任何靜態網頁空間（Netlify、Vercel、GitHub Pages 都行），
手機和電腦連同一個網址就好。

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 解析器測試（34 項）
npm run build    # 型別檢查 + 打包
```

### 專案結構

```
src/
  db/       資料模型、IndexedDB、Supabase 同步
  nlp/      中文排課語句解析器、AI 備援、寫入邏輯
  ui/       畫面
  lib/      日期、人數、文字工具
supabase/
  schema.sql   雲端資料表
```

解析器是純函式，`src/nlp/parse.test.ts` 裡有 34 個測試案例
（包含你原本那句範例）。要調整助理的理解方式，改 `src/nlp/parse.ts`，
順手把新的說法加進測試就不會改壞。

---

## 資料放在哪

- **本機**：瀏覽器的 IndexedDB，離線可用
- **雲端**：你自己的 Supabase 專案，有 Row Level Security，只有你的帳號讀得到
- **AI key**：只存本機，不上傳

沒設定 Supabase 的話，資料就只在那台裝置上。
記得偶爾用「設定 → 備份與還原」匯出一份。
